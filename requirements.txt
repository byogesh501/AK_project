# AK Visual Intelligence Platform
# ================================
#
# A multi-domain visual inspection and anomaly detection system.
# PCB/electronics inspection is the first supported domain.
#
# Project structure:
#   platform/     — Domain-agnostic core (preprocessing, models, anomaly, risk, explainability)
#   domains/      — Domain-specific code (domains/pcb/ for PCB inspection)
#   api/          — REST API (FastAPI)
#   dashboard/    — Interactive dashboard (Streamlit)
#   config/       — Configuration files
#   data/         — Datasets (raw data is gitignored)
#   tests/        — Test suite (mirrors source layout)
#   docs/         — Documentation
#   scripts/      — Utility scripts
#
# Quick start:
#   1. python -m venv .venv
#   2. .venv\Scripts\activate        (Windows)
#      source .venv/bin/activate     (Linux/macOS)
#   3. pip install -r requirements.txt
#   4. pytest                        (run placeholder tests)
#
